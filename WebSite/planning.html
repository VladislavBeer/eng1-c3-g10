The team adopted an Agile development approach, as it entails continuous testing, feedback collection, and the implementation of changes throughout the entire development process. GitHub was used for version control, Google Workspace for collaborative documentation, PlantUML and draw.io for diagramming, and the LibGDX framework paired with the VS Code editor for game development. Team communication took place via Discord. These tools were selected primarily because they aligned with the Agile methodology and the existing experience of the team members
